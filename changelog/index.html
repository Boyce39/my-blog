v5.2.0 (2026-09-09)

可靠語言切換、長文章翻譯與全新文章編輯器

  • 🌐 首頁語言切換修正：改用系統原生語言選單，完整支援滑鼠、鍵盤與手機觸控，切換時保留目前頁面與網址參數
  • 📱 響應式選單驗證：完成桌面與 390px 手機版實際操作，語言控制保持可見且頁面不產生橫向溢出
  • 📚 長文章翻譯修復：移除原本過低的 180 區塊拒絕條件，可處理最多 1,200 個文字區塊，並在平台限制內優先翻譯主要長段落
  • ⚡ 翻譯穩定度提升：同時翻譯數降為兩路、暫時性容量或逾時錯誤自動重試，並避免標題、摘要與 SEO 重複耗用額度
  • 🔁 翻譯失敗可重試：不再要求讀者反覆切換語言；失敗或逾時時保留原文，並可直接在文章上重新翻譯
  • ✍️ 文章工作室升級：導入 Tiptap 開源編輯器，支援可靠換行、復原重做、格式工具、連結、圖片拖放與可視化尺寸／對齊調整
  • 🖼️ 圖片操作改善：新增圖片選取框、拖曳縮放、320／560／820px 快速尺寸、左右置中對齊、替代文字與刪除操作

v5.1.0 (2026-09-02)

文章自動翻譯與寬敞工作室

  • ✦ 文章按需自動翻譯：既有 Hexo 文章與後台文章都能在讀者切換語言時由 Cloudflare Workers AI 翻譯，不必手動建立四份內容
  • ⚡ D1 翻譯快取：第一次翻譯後保存結果，後續讀取直接使用快取；文章內容變更時會自動產生新版，不沿用過期翻譯
  • ✍️ 人工版本優先：後台仍可校對或自行撰寫翻譯，人工版本永遠優先於自動翻譯
  • 🧩 保留文章結構：翻譯只處理可閱讀文字，保留標題、圖片、連結與程式碼內容
  • 🖥️ 工作室版面重構：放大主要寫作區、縮減側欄、將發布與封面設定移至下方，新增文章列表收合與專注寫作模式
  • 📱 多尺寸互動修正：修正語言分頁被標題區覆蓋，並完成桌面、平板與手機無橫向溢出的操作驗證
  • 🧭 後台網址容錯：輸入 /admin、/dashboard、/login、/studio 或 /editor 時會自動導向正確後台，不再顯示 404
  • 🔄 後台同步修復：修正管理網域誤把匿名訊息、AI 紀錄、文章留言與友站管理 API 當成靜態檔案，登入後不再顯示「同步失敗：404」

  • 🌐 首頁翻譯補齊：完善英文、日文、韓文的自我介紹、成就、聯絡與頁尾文字
